네트워크 통신을 할 때 기본적으로 OSI 7계층 모델 혹은 TCP/IP 4 계층 모델에 맞춰 동작한다. 
  
## 1. 네트워크 통신이 이루어지는 과정
    
- 브라우저에서 url 입력
- 브라우저는 이를 네트워크에서 통신 가능한 형태인 패킷으로 만든다.
- 이 패킷을 네트워크에 흘려보낸다.
- 네트워크 중간에 있는 기기(라우터)들이 이 패킷을 읽고 서버로 전달한다.
- 서버는 이 패킷을 다시 풀어 웹서버가 읽을 수 있는 형태로 만들고 웹서버에 전달한다.
    
뭉뚱그려 패킷이라고 표현했지만, OSI 7계층 각각 다른 이름(메세지, 세그먼트, 패킷, 프레임) 이 있다.
    
    
## 2. 네트워크 통신을 OSI 7계층 모델로 이해하기
    
<img width="580" height="388" alt="Image" src="https://github.com/user-attachments/assets/114ed937-3902-426b-9e41-a6e0b0a82d9c" />
        
그림에서 클라이언트는 송신 호스트가 되고, 서버는 수신 호스트가 된다.
    
- 먼저 브라우저라는 응용(애플리케이션)계층에서 URL을 입력한다.
- 이 데이터는 전송 전에 내부적으로 표현계층, 세션계층, 전송계층, 네트워크계층, 데이터링크계층을 차례대로 지나며 네트워크 통신에 필요한 데이터를 기존 데이터에 추가한다.
  - 각 계층은 순서를 가지며 응용계층 -> 물리계층 순으로 전달된다.
  - 각 계층은 이전 계층으로부터 데이터를 전달받으며, 자신의 계층에서 필요한 데이터들을 기존 데이터에 추가로 붙인다. 
- 물리 계층에서는 이렇게 계층을 지나며 만든 데이터를 실제로 네트워크에 전송한다.
- 서버는 이 데이터를 수신받아 다시 물리계층 -> 응용계층 순으로 전달한다.
- 각 계층은 마찬가지로 이전 데이터로부터 데이터를 전달받으며, 필요한 데이터만 분리하여 해석한다.
- 최종적으로 응용계층에서는 요청을 웹서버에 전달한 뒤 웹서버는 송신자에게 필요한 응답(웹 메인 페이지)를 다시 데이터로 만들게 된다. 
    
    
## 3. 프로토콜 
    
통신을 위한 형태 또는 규약을 프로토콜이라고 한다.    
HTTP, TCP, UDP가 프로토콜의 대표적 예시이다.     
    
## 4. OSI 7계층 모델
- OSI 7 계층이란, 네트워크 통신의 과정을 7단계로 나눈 설계를 의미한다.
- 이렇게 계층을 나누면 아래와 같은 장점이 있다.
  - 전체적으로 필요한 일을 여러 계층으로 나누면, 계층별 해야 할 일이 명확해진다.
  - 전체적인 설계 모델이 있으므로써 설명하기도 이해하기도 쉽다.
  - 각 층을 나누면 각 층별로 필요한 데이터들을 표준화할수도 있다. 
- OSI 7계층 모델은 국제표준화기구에서 개발한 네트워크 통신 표준 모델이다. 
    
    
## 5. 각 계층이 하는일
   
<img width="768" height="581" alt="Image" src="https://github.com/user-attachments/assets/0dc87ebf-4548-4b3e-b925-a8dfbc07cc61" />
    
#### 계층 7 : 응용계층(Application Layer)
- 이 계층은 웹서비스의 UI부분, 사용자의 입출력(I/O)을 담당한다.
- 프론트엔드, 백엔드 서버가 바로 이 레이어 위에서 동작한다.
- 대부분 사람이 사용하는 웹서비스는 이 레이어 위에서 제공된다.
    
#### 계층 6 : 표현계층(Presentation Layer)
- 응용 계층과 네트워크 계층을 위해 계층 간 데이터를 적절히 표현하는 부분을 담당한다.
- 이미지 압축, 데이터 암호화 등의 기능이 이 레이어 위에서 동작한다.
    
#### 계층 5 : 세션 계층(Session Layer)
- 통신을 실제로 “세션”이라고 하는 단위 위에서 이루어지는데, 이 계층은 이러한 통신 세션을 구성한다.
    
#### 계층 4 : 전송 계층(Transport Layer)
- 컴퓨터로 들어온 네트워크 데이터를 어느 포트(어느 프로세스)로 보낼지 담당한다.
- 하나의 컴퓨터에는 여러 프로세스가 동작하고 있으며 프로세스마다 별도의 네트워크 포트를 가지게된다.
- 네트워크가 끊기거나 데이터가 잘못된 것은 없는지 등 신뢰성 있는 데이터를 보장하는 역할을 담당한다.
    
#### 계층 3. 네트워크 계층 (Network Layer)
- IP주소를 사용하여 네트워크 데이터를 어느 컴퓨터로 보낼지 담당한다.
- IP주소는 컴퓨터 하나당 부여되지만, 중간에 바뀔 수 있으며 소프트웨어적으로 존재하는 개념
- 라우터 라는 기계가 이러한 역할을 해준다. 
    
#### 계층 2.  데이터 링크 계층 (Data Link Layer)
- 네트워크 가드의 MAC 주소를 사용해 네트워크 데이터를 어느 컴퓨터로 보낼지 담당한다.
- MAC주소는 랜카드당 하나 존재한다.
- IP주소와는 다르게 변하지 않으며 하드웨어 자체에 포함되는 개념이다. 
    
#### 계층 1 : 물리 계층 (Paysical)
- 디지털 데이터를 아날로그적인 전기적 신호로 변환하여 네트워크 전선에 흘려보낸다.
- 네트워크 전선은 0101 과 같은 디지털 신호를 이해할 수 없다.
- 따라서 이런 디지털 데이터를 네트워크 전선이 이해할 수 있는 아날로그 형태로 바꾼다.
- 반대로 아날로그 신호를 디지털 신호로 바꾸는 역할도 한다. 
   
      
## 6. TCP/IP 4계층
   
   <img width="612" height="408" alt="Image" src="https://github.com/user-attachments/assets/dde3bd80-fde3-4acf-b6c1-2805afea2fef" />
   
- OSI 7 계층 모델은 네트워크 통신 표준화를 위한 개념 모델이다.
- 실제로 인터넷 통신이 이렇게 동작하지는 앟고 이렇게 계층을 나누어 통신하도록 설계하자는 국젶준화기구의 제안이다.
- 실제 대부분의 인터넷 통신은 IP와 TCP에 기반한 TCP/IP 통신을 사용한다.
- 이 통신에 특화된 네트워크 통신 계층 모델이 따로 존재하는데 이를 “TCP/IP 4계층 모델”이라고 한다.
- OSI7계층과 유사하지만, 4계층으로 간소화되어있다. 
   
#### 계층4 : 응용계층 (Application Layer)
- OSI 7 계층 모델의 7,6,5(응용, 표현, 세션) 계층 기능을 담당한다.
- HTTP, Telnet, SSH, FTP와 같은 프로토콜이 여기에서 사용된다. 
   
#### 계층 3 : 전송 계층 (Transport Layer)
- OSI 7 계층 모델의 4(전송) 계층과 같다. 프로세스간의 신뢰성 있는 데이터 전송을 담당한다.
- TCP, UDP 와 같은 프로토콜이 여기에서 사용된다.
   
#### 계층 2 : 인터넷 계층(Internet Layer)
- OSI 7 계층 모델의 3(네트워크) 계층과 같다. 컴퓨터 간 라우팅을 담당한다. 
   
#### 계층 1 : 네트워크 인터페이스 계층 (Network Interface Layer)
- OSI 7계층 모델의 2, 1(데이터링크, 물리)계층과 같다.
- 네트워크 통신의 물리적인 부분들을 주로 포함한다.  
   
   
## 7. HTTP / HTTPS
   
- HTTP
  - Hyper Text Transfer Protocol 의 약자
  - 텍스트 문서를 주고 받기 위해 만들어진 프로토콜이다.
  - 일상에서 사용하는 웹브라우저와 서버가 이 HTTP를 사용하여 정보를 주고받는다.
  - 이는 보안에 취약하다. 웹사이트에서 로그인 할 때 비밀번호가 통신 과정 중 그대로 노출된다.
  - 통신 과정에도 응용 계층의 데이터를 암호화할 필요성이 느껴졌다.
  - 이로 인해 보안을 위한 레이어 SSL(Security Socket Layer, 현재는 TLS라는 명칭으로도 사용된다)가 생기게 된다. 이 레이어는 응용 계층과 전송 계층 사이에 존재한다.
   
- HTTPS
  - 보안의 역할을 하는 SSL 계층을 기반으로 하는 HTTP 통신을 HTTPS라고 한다.
  - HTTPS는 통신 보안을 포함하고 있으므로 HTTP보다 좋다.
  - 내용을 암호화하고 복호화하는 로직이 추가되어있어 기존 통신보다 로직이 좀 더 복잡해진다.
      
   
## 8. 정리
   
- OSI 7 계층 모델
  - ISO가 발표한 네트워크 통신 표준 모델이다 (개념모델)
  - 각 계층은 저마다의 맡은 기능이 있으며, 사용하는 프로토콜도 다르다.
  - 각 계층은 직전 계층에서 데이터를 전달받으며, 필요한 데이터를 붙여서 다음 계층으로 보낸다.
  - 우리가 송신자면 7계층(L7)부터 시작해 1계층(L1)까지 데이터를 만들어 보낸 뒤, 수신자는 다시 1계층부터 7계층까지의 과정을 거쳐 최종적으로 데이터를 받는다.
- TCP/IP 4 계층 모델
  - TCP/IP 는 보통 많이 쓰는 TCP/IP 통신에 기반한 네트워크 통신 모델이다.
  - OSI 7 계층과 유사하지만 4계층으로 간소화되어있다.
