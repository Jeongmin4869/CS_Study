
# 4. 클린코드
   
## 01 클린코드 - 네이밍 
   
   
### 코딩 함수명 컨벤션
- snake_case : Python, Ruby 등에서 권장
- camelCase : Java, Javascript 등에서 권장
- PascalCase : 클래스를 네이밍 할 때 사용
- Kebab-case : HTML element를 표현할 때 사용
   
### 변수와 상수
- 명사 혹은 형용사 구문 형태
```python
user_data = ... #명사
is_valid = ... #형용사

```
   
### 함수와 메서드
- 동사 혹은 형용사 구문 형태 
```python
def send_data():
    ...

def input_is_valid():
    ...

```
   
### 클래스
- 명사 구문 형태
```python
class Client:
    ...

class RequestBody:
    ...

```
